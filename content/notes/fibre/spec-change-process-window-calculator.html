改规格工艺窗口计算器

POY 改规格时，按单丝纤度定车速，用纤度闭环定泵供量，再检查喷丝头拉伸倍数、剪切速率和单丝纤度变化。

输入

基准规格（已知落在窗口内）

喷丝板与熔体

目标规格

k 标定（可选）

取两组落在加工窗口内的工艺，反推本厂指数 k = ln(Vb/Va) / ln(dpf_b/dpf_a)。

结果只给初值。泵频与排量只有在标定区段内才近似线性；落地前用动态热拉伸张力闭环确认一次。 剩余拉伸倍数参考线取自《涤纶长丝生产》表 4-2（2500 / 3000 / 3500 m/min 对应 2.1 / 1.8 / 1.6）。

公式：V0 = 4Q / (N·π·d²·ρ)；R′ = V / V0；D = 10000·Q / V；R′·D = 2500·π·ρ·N·d²。 车速按 V2 = V1·(dpf2/dpf1)^k 标定，泵供量按 Q2 = Q1·(D2/D1)·(V2/V1) 闭环。
